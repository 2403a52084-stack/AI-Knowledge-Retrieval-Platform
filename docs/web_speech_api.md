# Web Speech API Integration

## Speech-to-Text

The Web Speech API can convert the user's spoken question into text.

Flow:

Voice Input
↓
Speech Recognition
↓
Text Query
↓
RAG Query Processing
↓
Generated Answer

## Text-to-Speech

The Web Speech API can convert the generated answer into spoken audio.

Flow:

Generated Answer
↓
Speech Synthesis
↓
Voice Output

## Features

- Voice-based query input
- Browser speech recognition
- Spoken response
- Hands-free interaction
- Integration with the knowledge retrieval interface

## Browser Compatibility

Speech recognition and speech synthesis depend on browser support and microphone permissions.
